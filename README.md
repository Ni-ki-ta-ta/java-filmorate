# Filmorate

Filmorate — учебное REST-приложение для работы с фильмами, пользователями, рейтингами и жанрами.

Проект реализован на Java и Spring Boot. Данные приложения хранятся в базе данных H2 и сохраняются между перезапусками.

## Возможности

### Фильмы

- создание фильма;
- обновление фильма;
- получение фильма по ID;
- получение списка всех фильмов;
- добавление и удаление лайков;
- получение списка популярных фильмов;
- указание рейтинга MPA;
- указание жанров фильма.

### Пользователи

- создание пользователя;
- обновление пользователя;
- получение пользователя по ID;
- получение списка всех пользователей;
- добавление и удаление друзей;
- получение списка друзей;
- получение общих друзей.

Дружба является односторонней: если пользователь добавляет другого пользователя в друзья, он появляется только в его списке друзей.

### Жанры

- получение списка всех жанров;
- получение жанра по ID.

Доступные жанры:

1. Комедия
2. Драма
3. Мультфильм
4. Триллер
5. Документальный
6. Боевик

### Рейтинги MPA

Используется американская система MPAA:

| ID | Рейтинг |
|---:|:--------|
| 1 | G |
| 2 | PG |
| 3 | PG-13 |
| 4 | R |
| 5 | NC-17 |
