# Filmorate

**Filmorate** — backend-сервис для работы с фильмами и пользователями. Он помогает выбирать фильмы на основе пользовательских предпочтений, лайков и активности друзей.

Проект разработан в рамках командной работы. В ходе разработки реализованы дополнительные возможности: поиск фильмов, режиссёры, отзывы, рекомендации, лента событий и другие функции.

## Возможности

### Фильмы
- Создание, просмотр, обновление и удаление фильмов.
- Добавление и удаление лайков.
- Получение списка самых популярных фильмов.
- Фильтрация популярных фильмов по жанру и году выпуска.
- Поиск фильмов по названию и имени режиссёра.
- Получение фильмов конкретного режиссёра с сортировкой по количеству лайков или году выпуска.
- Получение общих фильмов двух пользователей с сортировкой по популярности.

### Пользователи
- Создание, просмотр, обновление и удаление пользователей.
- Добавление и удаление друзей.
- Получение списка друзей пользователя.
- Получение списка общих друзей.

### Жанры и возрастные рейтинги
- Получение списка жанров и жанра по идентификатору.
- Получение списка возрастных рейтингов MPA и рейтинга по идентификатору.
- Использование жанров и рейтингов при работе с фильмами.

### Отзывы
- Создание, изменение и удаление отзывов.
- Получение отзыва по идентификатору.
- Получение отзывов о фильме.
- Оценка полезности отзыва с помощью лайков и дизлайков.
- Сортировка отзывов по рейтингу полезности.

### Рекомендации
- Получение рекомендаций фильмов на основе сходства пользовательских предпочтений и лайков.

### Лента событий
- Просмотр истории действий пользователя.
- Отслеживание добавления и удаления друзей.
- Отслеживание добавления и удаления лайков.
- Отслеживание создания, изменения и удаления отзывов.

## Технологии

- **Java** — основной язык разработки.
- **Spring Boot** — создание backend-приложения и REST API.
- **JDBC / JdbcTemplate** — взаимодействие с базой данных.
- **H2 Database** — хранение данных.
- **Maven** — управление зависимостями и сборка проекта.
- **Lombok** — сокращение шаблонного кода.
- **JUnit** — автоматизированное тестирование.
- **Postman** — проверка REST API.

## Архитектура проекта

Приложение организовано по слоям:

- **Controller** — обработка HTTP-запросов и формирование ответов API.
- **Service** — бизнес-логика приложения и проверка входных данных.
- **Storage** — работа с данными и выполнение операций с базой данных.
- **Model** — модели предметной области: фильмы, пользователи, жанры, рейтинги и другие сущности.
- **Exception** — обработка ошибок и исключительных ситуаций.
- **Resources** — конфигурация приложения и SQL-скрипты для работы с базой данных.

Такое разделение позволяет отделить обработку HTTP-запросов от бизнес-логики и доступа к данным.

## Хранение данных

Для хранения данных используется H2. В рабочем режиме база хранится в файле:

```text
./db/filmorate
```

Структура таблиц и связи между сущностями определяются SQL-скриптом `schema.sql`. Начальные данные загружаются с помощью `data.sql`.

Доступ к данным реализован через JDBC и `JdbcTemplate`.

## Результат

В рамках проекта реализован REST API для сервиса Filmorate с поддержкой работы с фильмами, пользователями, лайками, друзьями, отзывами, рекомендациями и историей событий. Командная разработка позволила объединить отдельные функциональные модули в единое приложение и проверить их совместную работу.
